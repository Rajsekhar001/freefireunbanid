Privacy Policy & Local Verification Notice

1. Zero Screenshot Uploads

Screenshots selected during Step 2 are read exclusively inside your web browser using local object URLs for preview and dimension validation. Images are never uploaded, transmitted, or stored on any external server or database.

2. Local Verification Disclaimer

The confirmation step is a local browser check and user attestation only. This site does not connect to Instagram’s private APIs or claim automated server-side follow verification.

3. Browser Storage (localStorage & sessionStorage)

We use browser storage solely to remember whether you completed the local verification gate, save your APEX PHONK MODE audio preferences, and prevent duplicate visitor counts within the same tab session.

4. Anonymous Public Counters

When CounterAPI v2 is configured, anonymous numeric increment requests are sent for total visitors, Instagram clicks, Telegram clicks, and screenshot submission attempts. No personal identifiers or image files are collected.
