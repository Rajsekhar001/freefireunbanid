## How to Publish Free on GitHub Pages (2 Minutes)

1. Create a **Public** repository on GitHub (for example: `apex-id-unban-bot`).
2. Upload all project files (`index.html`, `style.css`, `config.js`, `script.js`, `.nojekyll`, and the `assets/` folder) directly into the repository root.
3. Open your repository **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Select **Branch: `main`** and folder **`/ (root)`**, then click **Save**.
6. Wait ~30–60 seconds and open your live free link: `https://<your-username>.github.io/<repo-name>/`.

*(You do NOT need `npm install`, Node.js, or any paid plan — it works straight from the root files!)*
